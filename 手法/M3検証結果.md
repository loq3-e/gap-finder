## 不一致・要考察ケースの原因分析

### ケース5（曖昧ケース）：一致と判定したが、CASE5と同型の問題を再現

想定はLA-DET-03／LA-DET-06のどちらとも取れる曖昧ケースとして設計し、confidence="low"を期待した。実際の出力はLA-DET-06のみをconfidence="high"で断定しており、M2のCASE5（`手法/M2確認用サンプルケース.md`）と全く同じ「前提側ではなく下流概念に一方的に吸着する」パターンが再現した。

方針書の判定基準（confidenceは一致率の判定に使わない）に従えば、LA-DET-06は想定2候補のうちの1つなので形式上は**一致**。ただし「本当に拮抗する曖昧さを再現できているか」という設計目的は達成できておらず、`手法/M3疑似データ作成方針.md` の事前チェックで指摘していたリスクがそのまま的中した。LA-DET-03とLA-DET-06は評価材料としては妥当だが、AIにとっては非対称（LA-DET-06に偏る）であることが2回（M2 CASE5、M3ケース5）続けて確認された。

### ケース7：単一概念想定に余分な候補（LA-DET-06）が出力された

自己説明は「固有値が『Av=λvを満たすλ』という意味であることは特に意識せず」という記述のみで、det=0や正則性には一切言及していない。出力の(b)はLA-EIG-01とLA-DET-06の両方に対して**同一の引用文**を根拠として使っており、LA-DET-06側には自己説明文中の固有の裏付けがない。

→ 自己説明文自体は狙い通りLA-EIG-01を具体的に指しており、ケース設計の問題とは考えにくい。AIがこじつけ的にLA-DET-06を追加したと判断し、**不一致**とする。

### ケース9：想定概念(LA-DIAG-01)が出力されず、別の概念(LA-DIAG-02)に置き換わった

学習者は固有ベクトルを求めずに「P=元の行列A、D=単位行列」とした。これはPとDの役割（P:固有ベクトル、D:固有値）そのものを取り違えているLA-DIAG-01の誤解と直接対応する。一方LA-DIAG-02は「固有ベクトルを求めた後の並べる順序」の誤りを扱う概念であり、本ケースは固有ベクトルを求めてすらいないため、LA-DIAG-02のevidence_patternsが指す状況（順序のズレ）とは一致しない。

→ 自己説明文（「Pには元の行列A、Dには対角行列を当てはめればいい」）はLA-DIAG-01の定義・誤解に明確に対応しており、ケース設計の問題とは考えにくい。AIがLA-DIAG-01とLA-DIAG-02を混同したと判断し、**不一致**とする（LA-DIAG-03は一致）。

## 根拠妥当性の判定

`手法/M3疑似データ作成方針.md` の基準（(1)引用箇所が実在する／(2)概念との論理的対応がある）で確認。

- 1〜4, 6, 8, 10：(1)(2)とも満たす
- 5：(1)(2)とも満たす（LA-DET-06に対する論理的対応自体は成立している。問題は曖昧さの設計目的が達成されなかった点であり、根拠妥当性そのものは問題ない）
- 7：LA-EIG-01については(1)(2)とも満たすが、LA-DET-06については(1)は満たす（引用文自体は実在）が(2)の論理的対応が弱い（自己説明文にdet=0や正則性への言及がない）
- 9：LA-DIAG-03については(1)(2)とも満たすが、LA-DIAG-02については(2)の論理的対応が成立しない（固有ベクトルを求めていないため「順序のズレ」という状況自体が発生していない）

**根拠妥当性：8/10が完全に妥当（80%）** → 達成基準70%以上を満たす（ケース7・9は一部の概念IDについてのみ根拠が弱い）

## 気づき

- **LA-DET-06への「吸着」が2回（M2のCASE5、M3のケース5・7）観測された。** 「公式を理由もわからず適用した」系の自己説明は、話題が固有値・行列式のどちらであってもLA-DET-06を引き寄せる傾向がある。LA-DET-06のevidence_patternsの文言（「公式のみ適用し、理由づけがない」）が汎用的すぎて、他の章の概念と比較したときに不当に有利になっている可能性がある。次のイテレーションでLA-DET-06のevidence_patternsをより固有値文脈（A-λI）に限定するか、逆に意図的に「理由がわからない」系ケースでの基準候補として扱うかを検討する価値がある
- **ケース9の失敗は、評価対象概念が前提関係にある場合（DIAG-01とDIAG-02、ともにDIAG-03の前提）、AIが"手順の詳細（DIAG-02）"と"定義レベルの誤解（DIAG-01）"を混同しやすいことを示唆する。** 根本的な役割の取り違え（DIAG-01）と、手順の中の順序ミス（DIAG-02）の境界が概念ID設計上あいまいな可能性がある

## 達成基準との対応

- [x] 疑似データケース最低10件作成（曖昧な自己説明パターン・誤答パターンを含む） → 10件、4パターン
- [x] 想定ラベルとの一致率70%以上 → 80%（8/10）
- [x] 根拠の妥当性70%以上 → 80%（8/10）
- [x] 出力フォーマットエラー率0% → 0/10

M3の数値上の達成基準は満たしているが、ケース5・7・9で見つかった課題（LA-DET-06の吸着、DIAG-01/02の混同）は概念ID体系側の見直し候補として記録し、次のステップ（M4）に進む前、または概念ID体系の追加修正タイミングで検討する。
