# 進捗報告書

## 目的
数学学習において、生成AIが学習者の解答過程（問題文＋途中式＋自己説明）から「概念理解の不足」を根拠付きで推定し、概念マップとして可視化することで、学習者の自己評価の較正とメタ認知能力の向上を支援できるかを検証する。

## 現状
- AI出力パイプラインの仕様を設計：入力（問題文＋解答＋自己説明）に対し、(a)不足概念候補 (b)根拠 (c)確信度 (d)内省質問 を出力
- 概念ID定義の方法論を設計（教科書の章立てをベースに、1概念＝1根拠パターンで判定可能な粒度、前提関係を持たせる）
- 理想データ1ケース（固有値・固有ベクトル問題）でGemini 3.6 Flashによるプロトタイプテストを実施

```json
{
  "a": [
    {
      "id": "LA-EIG-02",
      "name": "非自明解の存在条件"
    }
  ],
  "b": "解答で |A - λI| = 0 をそのまま適用して計算を進めている点、および自己説明で「det(A - λI) = 0 を使えば固有値が求められると知っていたが、なぜこれをすればよいか分からない」と記述している点。",
  "c": "high",
  "d": "固有ベクトルの定義式 (A - λI)v = 0 において、もし v が 0 ベクトル（自明解）以外の解（非自明解）を持つとしたら、行列 (A - λI) の行列式 (det) はどのような値をとる必要があるでしょうか？"
}

```

-  上記のような出力が得られ、この理想データであればフローで問題ないことを確認

## 課題
理想データ1件（固有値・固有ベクトル問題）でのプロトタイプ検証により(a)〜(d)の出力フロー自体は成立することを確認したが、以下が未整備であり、この流れを線形代数1単元全体で安定して実行できる状態には至っていない。

- 概念ID体系が固有値・固有ベクトル単元の一部（LA-EIG-01, 02の2件）にとどまっており、線形代数1単元全体をカバーできていない
- 理想データ1件のみの検証であり、曖昧な自己説明や誤答を含む疑似データケースでのパイプライン頑健性が未確認
- メタ認知能力向上（自己評価と概念テスト結果のズレの変化）を測る具体的な評価手法・実験デザインが未設計

## マイルストーン
以下、線形代数1単元全体で(a)〜(d)のフローを実行し、メタ認知能力向上の測定手法まで設計することを目標とする。
学習者にデータをとってもらう部分はマイルストーンにまだ入れていない。

1. M1:概念ID体系の構築（線形代数1単元全体）
   - 教科書の章立てをベースに、1概念＝1根拠パターンで判定可能な粒度で概念を洗い出し、前提関係（prerequisites）・evidence_patterns・misconceptionsを整備する
   - **達成基準**：
     - 対象範囲（教科書の該当単元の章立て全体）に含まれる項目への概念ID付与網羅率100%
     - 各概念IDについてdefinition／prerequisites／evidence_patterns（1件以上）／misconceptions（1件以上）の記入率100%（欠損0件）
     - prerequisitesの依存関係に循環参照が0件（DAGとして整合）
2. M2:プロンプトの更新・完成
   - 拡充した概念IDリストをプロンプトに統合し、(a)〜(d)の出力形式を固定する
   - **達成基準**：
     - M1で構築した概念ID全件がプロンプトの概念IDリストに反映されている（反映率100%）
     - M3の疑似データケース全件に対し、出力JSONが指定スキーマに準拠（パース成功率100%、概念IDリスト外の値を出力した件数0件）
3. M3:疑似データケースによるパイプライン頑健性検証
   - 曖昧な自己説明・誤答を含む疑似データケースを複数自作し、(a)〜(d)の出力が概念IDリストと整合し安定して得られるかを検証する
   - **達成基準**：
     - 疑似データケースを最低10件作成（曖昧な自己説明パターン・誤答パターンを含む）
     - 各ケースについて自己判定した正解概念IDと(a)の一致率70%以上
     - (b)の根拠が解答・自己説明文中の該当箇所を正しく指し示している割合70%以上
     - 出力フォーマットエラー率0%
4. M4:メタ認知能力測定手法の設計
   - 自己評価（概念ごとの「できる度」）の測定方法、概念テストの設計、両者のズレの算出方法を設計する（実際の被験者実験の実施は対象外、設計のみ）
   - **達成基準**：
     - 自己評価アンケート項目・概念テスト問題・ズレの算出式（例：|自己評価スコア－テスト正答率|）が文書として完成している
     - 自分自身または少人数でのパイロット実施により、ズレの値が実際に算出可能であることを確認する
