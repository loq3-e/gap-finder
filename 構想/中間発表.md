# 生成AIによる概念理解不足の推定と可視化を通じたメタ認知支援

- 研究概要
    - 数学学習では、学習者が自身の理解度を客観的に把握できないこと（自己評価の不正確さ）が、メタ認知能力の低さ・学習効率の低下につながっていると考えられる
    - 本研究は、学習者の解答過程（問題文＋途中式＋自己説明）を生成AIに分析させ、不足している概念とその根拠を推定・可視化することで、学習者が自己評価を較正し、メタ認知能力を高められるかを検証する
    - 対象は線形代数1単元。概念ID体系の構築（M1）→AI出力パイプラインの構築（M2）→疑似データによる頑健性検証（M3）→メタ認知能力測定手法の設計（M4）の4段階で進めている
    - 現時点でM1〜M3が完了し、学習者の解答・自己説明から不足概念を根拠付きで安定して推定できることを確認済み。今後はM4（自己評価とテスト結果のズレを測る手法の設計）に着手する

- 目的を達成するために必要なこと（定量化された基準）
    - 目的：数学学習において、生成AIが学習者の解答過程（問題文＋途中式＋自己説明）から「概念理解の不足」を根拠付きで推定し、概念マップとして可視化することで、学習者の自己評価の較正とメタ認知能力の向上を支援できるかを検証する
    - 線形代数1単元全体を対象に、(a)不足概念候補 (b)根拠 (c)確信度 (d)内省質問 を出力するパイプラインを安定動作させ、メタ認知能力向上の測定手法まで設計することをゴールとし、M1〜M4の4マイルストーンに分解。各マイルストーンに定量的な達成基準を設定した
        - M1（概念ID体系の構築）
            - 対象範囲への概念ID付与網羅率100%
            - 各概念IDのdefinition／prerequisites／evidence_patterns（1件以上）／misconceptionsの記入率100%（欠損0件）
            - prerequisitesの循環参照0件（DAGとして整合）
        - M2（プロンプトの更新・完成）
            - M1で構築した概念ID全件がプロンプトの概念IDリストに反映（反映率100%）
            - 確認用サンプルケース（3〜5件）全件で出力JSONが指定スキーマに準拠（パース成功率100%、概念IDリスト外の値0件）
        - M3（疑似データケースによるパイプライン頑健性検証）
            - 疑似データケースを最低10件作成（曖昧な自己説明パターン・誤答パターンを含む）
            - 自己判定した正解概念IDと(a)の一致率70%以上
            - (b)の根拠が解答・自己説明文中の該当箇所を正しく指し示している割合70%以上
            - 出力フォーマットエラー率0%
        - M4（メタ認知能力測定手法の設計）
            - 自己評価アンケート項目・概念テスト問題・ズレの算出式（例：|自己評価スコア－テスト正答率|）が文書として完成
            - 自分自身または少人数でのパイロット実施により、ズレの値が実際に算出可能であることを確認
- 達成基準への計画
    - M1：教科書（線形代数1、9章立て）をベースに、1概念＝1根拠パターンで判定可能な粒度で概念を洗い出し、前提関係（prerequisites）・evidence_patterns・misconceptionsを整備する
    - M2：M1で拡充した概念IDリストをプロンプトに統合し、(a)〜(d)の出力形式・制約（リスト外禁止、根拠の具体性、確信度の使い分け等）を固定する
    - M3：曖昧な自己説明・誤答を含む疑似データケースを複数自作し、(a)〜(d)の出力が概念IDリストと整合し安定して得られるかをAPI経由で検証する
    - M4：自己評価（概念ごとの「できる度」）の測定方法、概念テストの設計、両者のズレの算出方法を設計する（実際の被験者実験の実施は対象外、設計のみ）
    - なお着手前にM2↔M3の循環依存（M2の達成基準がM3の成果物を前提としていた）が判明したため、M2はM2内で自作するサンプルケース（3〜5件）で完結する形に設計を修正済み
